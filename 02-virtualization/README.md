# Virtualization

Documentation of virtual machine creation and virtual LAN configuration within the cybersecurity homelab.

## Labs

* Virtual machine creation
* Virtual hardware allocation
* Virtual disk configuration
* Virtual network creation
* Virtual LAN architecture
* Network segmentation

## Objectives

The virtualization portion of the lab focuses on developing practical experience with:

* Hypervisor configuration
* Virtual CPUs and memory
* Virtual storage
* Virtual network adapters
* Virtual LANs
* Network segmentation
* Isolated laboratory environments

## Security Considerations

Virtualization allows isolated environments to be created for cybersecurity training, testing, and experimentation.

Virtual LANs can further separate laboratory systems and control which systems share the same network segment.

## Documentation

Each lab documents:

1. Configuration
2. Architecture
3. Resources allocated
4. Network design
5. Security considerations
6. Lessons learned
