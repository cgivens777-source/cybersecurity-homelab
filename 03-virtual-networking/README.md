# Networking

Documentation of networking configuration, troubleshooting, traffic analysis, and virtual networking performed in the homelab between a linux and windows VM.

## Labs

* Home network architecture
* Ubuntu and Windows connectivity
* IP addressing and network troubleshooting
* Virtual networking
* Wireshark packet capture
* Network traffic analysis
* Firewall and network access control
* Network service identification

## Tools

* Linux networking utilities
* Windows networking utilities
* Wireshark
* UFW
* SSH
* ICMP

## Objectives

The networking portion of the lab is focused on developing practical understanding of:

* TCP/IP networking
* IP addressing
* Ports and protocols
* Network segmentation
* Host-based firewalls
* Remote administration
* Packet capture and analysis
* Network troubleshooting
